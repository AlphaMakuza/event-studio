View, measure, and compare.

Event-Based Studio brings recorded event data and live camera viewing into one desktop application. Open a CSV recording, move through its timeline, and select the regions and intervals you want to examine.

Compare activity between regions, filter event polarity, add annotations, and export your measurements. Projects retain the recording settings and analysis context, so you can return to an observation or share it with a colleague.

View and compare

Play recordings, filter event polarity, select regions, and compare activity over time.

Measure and export

Inspect intervals, run analysis, add annotations, and export event data or PNG images.

Save your work

Keep projects locally, recover unsaved changes, and move a project between computers with an .ebs file.

Live camera mode

Connect a compatible event camera and view incoming events while you adjust the setup. Inspect the live stream in RAW or Studio view, then record it to CSV for a closer examination afterward.

Live acquisition requires the native Metavision SDK and a supported camera driver, installed separately.

Factories and manufacturing

Use event recordings from production trials to study repetitive machinery, moving parts, or material flow. Select areas of a process, compare their activity over time, and examine the timing of individual movements.

This can support process investigation, equipment studies, and the development of inspection methods. Save regions, notes, and intervals with the project to keep each observation traceable.

CSV, cameras, and other formats

CSV, DAT and H5/HDF5 event recordings open with bundled readers, including ECF compression. No WSL or OpenEB setup is needed. Live cameras still need the Metavision SDK and drivers.
